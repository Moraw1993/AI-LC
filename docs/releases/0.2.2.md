# AI-LC 0.2.2

This release includes all changes integrated into `develop` since 0.2.1, including
audited replacement of assessment evidence and the separation of formative lesson
checks from formal independent assessments. The Codex Assessor profile uses a lower
reasoning effort for completed formal checkpoints.

Assessment corrections preserve the replaced judgment in the audit history while
using the active judgment for mastery, diagnosis and review scheduling. Ordinary lesson
checks remain in the Teacher conversation and do not trigger independent assessment.

Native release assets are built and smoke-tested for Windows x64, Linux x64/arm64 and
macOS x64/arm64. Install AI-LC with the release installer and configure each learning
workspace with `ailearn config --harness codex`.
