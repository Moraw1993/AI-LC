# AI-LC 0.2.0

Install AI-LC once per user with native Windows, Linux or macOS release installers.
The executable bundles Python, dependencies, domain packs and teaching instructions;
learning commands need no uv, separately installed Python or activated environment.
Downloads are verified with SHA256 and version checks; repeated installation preserves
identical versions and refuses conflicting or unrelated command files.

Run `ailearn config --harness codex` from a separate learning directory. Configuration
installs a topic-neutral hub, discoverable teaching skills and conservative Codex rules,
preserving existing user settings, instructions and learning state. Invoke `$ai-lc-master`
to agree your goal, level, course name and teaching style before any curriculum is chosen.
Teacher diagnoses prerequisites and current ability before roadmap creation; independent
Assessor evidence gates the baseline. Python implementation tasks use short, numbered
lesson/topic/attempt files. Materials, visualization, motion and Python lab skills remain
external-harness workflows, not bundled media services or an execution sandbox.

The legacy project-local installer remains supported. Existing v0.1 learner snapshots
remain readable; no automatic state migration or invented mastery is performed.
New configuration does not overwrite differing existing resource files. Resolve resource
conflicts explicitly while preserving learner snapshots and artifacts.

Supported assets: Windows x64; Linux x64/arm64; macOS x64/arm64. Platforms are built and
smoke-tested separately. Native installation never removes external harness sandbox
restrictions. Windows native CLI configuration, repeat configuration and doctor were
also independently verified in the Codex workspace-write sandbox.
